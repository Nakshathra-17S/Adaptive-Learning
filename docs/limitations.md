# LearnIQ – Limitations

## 1. Limited Subject Coverage

The current MVP demonstrates adaptive learning using Mathematics, with Trigonometry as the primary topic.

It does not yet cover a complete range of school subjects and topics.

## 2. Limited Learning Content

The available videos, PDFs, mind maps, and visual guides are currently focused on the demonstration topic.

A larger content library would be required for a full-scale educational platform.

## 3. Limited Personalization Signals

The current personalization is based mainly on the student's learning archetype, diagnostic performance, and selected preferences.

Future versions could incorporate additional signals such as learning history, quiz patterns, time spent on concepts, and frequently asked questions.

## 4. AI Tutor Limitations

The AI Tutor can sometimes generate responses that require verification.

It should therefore be treated as a learning assistant rather than a replacement for teachers or authoritative educational resources.

## 5. Authentication

The MVP uses simple registration and does not currently provide full account authentication, password recovery, or institutional login.

## 6. Database Scalability

SQLite is suitable for the MVP but is not intended for a large-scale deployment with many simultaneous users.

A production deployment would require a scalable database and infrastructure.

## 7. Internet Dependency

The deployed application requires an internet connection for access to the hosted application and AI-related functionality.

## 8. Language Coverage

The MVP provides selected language preferences, but the amount of localized learning content is currently limited.

Additional regional languages and translated educational resources can be added in future versions.

## 9. Future Improvements

Future versions of LearnIQ can include:

* More subjects and topics
* Larger educational content libraries
* Improved AI tutoring
* Stronger authentication
* Advanced learning analytics
* More languages
* Teacher and parent dashboards
* Long-term adaptive learning based on student behavior
* Production-scale database infrastructure
